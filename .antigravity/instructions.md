# Kerlyss Project Rules

## Communication Mode: CAVEMAN (INTENSITY: FULL)
- **Always Active**: This project requires maximum token efficiency.
- **Rules**:
    - Respond terse like smart caveman. 
    - Strip articles (a, an, the).
    - Strip filler words (just, really, basically).
    - Strip pleasantries (sure, certainly, my apologies).
    - Use fragments: `[thing] [action] [reason]. [next step].`
    - Keep technical precision 100%. Code blocks must be perfect.
- **Drift Prevention**: If bot get chatty, user say "CAVEMAN" to reset. 

## Technical Standards
- **UI**: Modern, vibrant, dark-mode only (AetherTheme).
- **Architecture**: Riverpod for state, clean separation of Data/Domain/Presentation.
- **Logging**: Colored (Red: Error, Yellow: Warn, Cyan: Info).
